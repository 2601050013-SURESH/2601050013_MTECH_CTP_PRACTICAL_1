# Binary Search Implementation

## Description

This project implements the Binary Search algorithm using Python. Binary Search efficiently finds a target element in a sorted list by repeatedly dividing the search range into two halves.

## Algorithm

1. Take a sorted list of elements.
2. Set the lower and upper limits.
3. Find the middle element.
4. Compare the middle element with the target.
5. If the target is equal to the middle element, return its position.
6. If the target is greater, search the right half.
7. If the target is smaller, search the left half.
8. Repeat until the element is found or the search range becomes empty.

## Input

A sorted list of integers and the element to be searched.

## Output

The program displays whether the element is found and its index.

## Example

### Input

10 20 30 40 50 60 70

50

### Output

Element found at index: 4
